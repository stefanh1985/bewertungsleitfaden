Am Bewertungsleitfaden mitwirken

Ein schlanker Workflow für neue Prüfungsformen – ohne Änderungen an den bestehenden Inhalten.

Empfohlener Ablauf

  1. Neue Prüfungsform fachlich klären und Material sammeln.
  2. KI-Assistent für Bewertungs- und Kompetenzraster öffnen und Inhalte nach der Vier-Ebenen-Struktur erstellen.
  3. Die Datei content/_vorlage-neue-pruefungsform.html kopieren und die Inhalte einsetzen.
  4. Neue Datei im GitHub-Repository ergänzen und auf der Startseite verlinken.
  5. Nach Veröffentlichung die Druckansicht und den Link testen.
Hinweis: GitHub Pages ist statisch. Die Website kann neue Inhalte anzeigen, sobald die entsprechenden Dateien im Repository gespeichert wurden. Eine direkte Speicherung aus dem Browser in GitHub benötigt zusätzlich eine Authentifizierungs-/CMS-Lösung.
